What goes inside each tab?

Each tab is a deep-dive panel. The class histogram stays anchored at the bottom across all tabs.

▣ Memory tab
┌─ Heap chart (2 lines: used + committed)
├─ Heap pools breakdown (stacked bars)
Eden / Survivor / Old / Metaspace / Code Cache
├─ GC timeline
per-collector spikes + cause + duration tooltip
├─ Direct + mapped buffer chart
└─ Allocation rate (MB/sec, derived)

Memory tab

Everything heap-related plus off-heap. The GC timeline is the critical addition — visual spikes with hover tooltip showing cause + duration. Allocation rate (derived from used-heap delta over time) helps spot allocation pressure.

▣ Threads tab
┌─ State donut: RUNNABLE / BLOCKED / WAITING / TIMED
├─ Thread count over time
├─ Top 10 threads by CPU (live, sortable)
name · state · CPU% · stack snippet
├─ Deadlock banner (red, when detected)
shows the cycle of locked threads
└─ Click any row → expand stack trace

Threads tab

Donut chart for state distribution. Top-by-CPU table shows what's actually working. Deadlock detection runs every 10s; if found, a red banner pops above the table with the cycle. Click a thread row to expand its stack trace inline.

▣ JVM internals tab
┌─ Runtime info (read-only)
vendor · version · uptime · args
├─ Class loading: loaded / total / unloaded
├─ JIT: compile time + method count
├─ OS: load avg · free RAM · swap · FDs
└─ System properties / env (collapsible)

JVM internals tab

The "what JVM am I actually running and what's it doing" tab. Static info (vendor, version, args) plus live counters. Class-loading delta is highlighted when it climbs steadily — classic classloader-leak signal.

▣ App tab
┌─ Source detector (Spring Boot vs Tomcat vs none)
├─ HTTP requests/sec + p50/p95/p99 latency
├─ Top endpoints by latency (Actuator)
├─ Health checks (Actuator /health)
├─ Log level inspector + live changer
│ (Actuator /loggers — change levels without restart)
└─ Tomcat MBean: busy threads, error count

App tab

App-level signals. Auto-detects source — Spring Boot Actuator (preferred) or Tomcat MBeans. Graceful degradation: if neither is reachable, tab shows "no app source detected — enable Spring Boot Actuator or use Tomcat for app-level metrics" instead of being broken.
