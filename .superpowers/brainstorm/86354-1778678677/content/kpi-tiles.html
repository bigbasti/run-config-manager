Pick the tile set you want (multi-select)

All include the chart above. Tiles get green/yellow/red based on thresholds + click-to-jump-to-tab.

H

Heap usage

used / max. Yellow @ 70%, red @ 90%. Click → Memory tab.

G

GC pause time

Cumulative GC ms in last 60s. Yellow @ 100ms, red @ 500ms. Click → Memory tab. Catches GC pressure before heap-usage even moves.

C

CPU

Process CPU%, now / avg. Yellow @ 70%, red @ 90% sustained. Click → Threads tab (top-CPU threads).

T

Threads

Total count + #BLOCKED. Yellow if BLOCKED > 0, red on deadlock. Click → Threads tab.

O

Off-heap

direct + mapped buffers MB. Yellow at 2× max-heap (suspicious for non-NIO apps). Click → Memory tab. Catches Netty/NIO-style leaks heap chart misses.

F

Open FDs

file descriptors open / max. Yellow @ 50%, red @ 80%. Click → JVM internals tab. Catches connection / file leaks.

R

HTTP req/s

App-level (Spring Boot Actuator / Tomcat MBeans). Tile only shows when source is available. Yellow @ p99 latency > 1s. Click → App tab.

L

Loaded classes

Loaded count + Δ. Yellow if Δ ≠ 0 over 60s steady state (catches classloader leaks). Click → JVM internals tab.

Pick anywhere from 4–8. Note: the visual shows 6, which is comfortable on a typical sidebar width.
