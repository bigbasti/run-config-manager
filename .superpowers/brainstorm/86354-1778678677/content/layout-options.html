How should we lay out the expanded Monitor view?

All 8 data categories will be there — the question is how to organize them so you can scan quickly and drill in when needed.

A. Long scroll page

Every section stacked vertically, top-to-bottom. Simple. Everything is one Ctrl+F away. But you scroll a lot, and 90% of the viewport is data you're not looking at right now.

B. Tabs only

Top-level tabs, each one shows one category. No mixing. Clean focus. Downside: you have to click around to know if anything is wrong elsewhere — you can't see at a glance whether GC is normal while looking at threads.

C. Dashboard + drill-down tabs

Recommended. Top: a compact "what's going on right now" header — chart + KPI tiles colored by health (green/yellow/red). Middle: tabs for deep dives (Memory, Threads, JVM internals, App). Bottom: class histogram (most-used existing panel) stays anchored. The KPI tiles double as health indicators — one red tile tells you which tab to click.
